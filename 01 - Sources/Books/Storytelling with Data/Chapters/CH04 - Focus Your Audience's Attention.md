# Chapter 04 — Focus Your Audience's Attention

## Summary

Covers how visual perception and memory work (iconic memory, short-term memory's ~4-chunk capacity, long-term memory) and introduces preattentive attributes — visual properties like color intensity, size, and position that iconic memory picks up before conscious thought — as the tool for directing an audience's attention to what matters and for building a visual hierarchy across the remaining (post-decluttering) chart elements.

## Claims

### Claim 1

Claim ID: `storytelling-with-data__ch04-C001`

Fingerprint: `9ef21f115f7e`

Text: Preattentive attributes (e.g. color intensity/hue, size, position on the page) are processed by iconic memory before conscious thought — demonstrated by a counting-task example where adding a single color cue to a block of numbers turns an effortful search into an instantaneous one. Because of this, preattentive attributes can be used strategically to direct an audience's attention to specific data points and to build a visual hierarchy that leads the audience through the remaining (already-decluttered) chart elements in a deliberate order.

Type: `mechanism`

### Claim 2

Claim ID: `storytelling-with-data__ch04-C002`

Fingerprint: `70ca37867532`

Text: Short-term (working) memory can hold only about four chunks of visual information at a time; a chart with many distinct colors/series/legend entries that the audience must repeatedly cross-reference against a separate legend exceeds this capacity and imposes avoidable cognitive burden — a design implication is to label data series directly rather than relying on a side legend wherever practical.

Type: `limitation`

Section: `Short-term memory`
