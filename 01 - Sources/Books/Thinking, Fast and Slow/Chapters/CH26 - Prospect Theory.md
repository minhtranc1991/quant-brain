## Summary

Kahneman's own first-person account of developing prospect theory with Amos Tversky: three core features — a value function defined on gains/losses relative to a reference point (not final wealth), diminishing sensitivity (both the gain and loss branches show decreasing marginal impact further from the reference point), and loss aversion (the loss branch is steeper than the gain branch) — jointly explain risk-averse choices for gains and risk-seeking choices for losses of matched expected value.

Text: Prospect theory's value function has three jointly necessary features, in the theory's originators' own framing: (1) evaluation is relative to a reference point, not final wealth (correcting Bernoulli's error); (2) diminishing sensitivity applies on both sides of the reference point (the psychological difference between a $900 and $1,000 gain/loss feels smaller than between a $0 and $100 gain/loss, symmetric for gains and losses); (3) loss aversion — the loss branch of the value function is steeper than the gain branch. Together these three features, not loss aversion alone, are required to reproduce the theory's signature fourfold pattern of risk attitudes (documented separately, Ch29).
